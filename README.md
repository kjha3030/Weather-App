# Weather App

A responsive weather application built using HTML, CSS and JavaScript.

## Features

- Search weather by city
- Real-time weather data
- Temperature
- Humidity
- Feels Like
- Wind Speed
- Day/Night Emoji
- Error Handling
- Enter Key Search

## Technologies Used

- HTML
- CSS
- JavaScript
- OpenWeather API

## How It Works

The application fetches real-time weather data from OpenWeather API using JavaScript Fetch API and displays it dynamically on the webpage.
